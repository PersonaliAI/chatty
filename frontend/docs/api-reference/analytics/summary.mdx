## Overview

Returns lifetime (or time-filtered) usage statistics: message volume, unique sessions, lead capture count, and knowledge base size.

**Required scope:** `read`

## Query parameters

<ParamField query="since" type="string">
  Filter to events after this ISO 8601 datetime (e.g. `2026-07-01T00:00:00Z`). If omitted, returns lifetime totals.
</ParamField>

## Response

<ResponseField name="bot_id" type="string">The bot this data belongs to.</ResponseField>
<ResponseField name="since" type="string">The `since` filter used, or `null` for lifetime.</ResponseField>
<ResponseField name="total_messages" type="integer">Total number of messages (all roles).</ResponseField>
<ResponseField name="user_messages" type="integer">Messages sent by visitors.</ResponseField>
<ResponseField name="bot_messages" type="integer">Replies sent by the AI.</ResponseField>
<ResponseField name="unique_sessions" type="integer">Number of distinct conversation sessions.</ResponseField>
<ResponseField name="total_leads" type="integer">Leads captured by the bot.</ResponseField>
<ResponseField name="knowledge_sources" type="integer">Number of knowledge sources currently indexed.</ResponseField>
<ResponseField name="knowledge_kb" type="integer">Total size of indexed content in kilobytes.</ResponseField>

```python Python — Build a weekly report
import httpx
from datetime import datetime, timedelta, timezone

client = httpx.Client(
    base_url="https://chatty-api-376030619262.us-central1.run.app",
    headers={"Authorization": "Bearer chatty_sk_your_key"},
)

# Last 7 days
since = (datetime.now(timezone.utc) - timedelta(days=7)).isoformat()
stats = client.get("/api/v1/analytics", params={"since": since}).json()

print(f"This week:")
print(f"  Sessions:  {stats['unique_sessions']}")
print(f"  Messages:  {stats['user_messages']} from visitors")
print(f"  Leads:     {stats['total_leads']}")
```

```javascript Node.js — Dashboard widget
async function getWeeklyStats() {
  const since = new Date(Date.now() - 7 * 24 * 60 * 60 * 1000).toISOString();
  const res = await fetch(
    `https://chatty-api-376030619262.us-central1.run.app/api/v1/analytics?since=${since}`,
    { headers: { Authorization: "Bearer chatty_sk_your_key" } }
  );
  return res.json();
}
```
