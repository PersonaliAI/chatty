---
title: "Get Bot Details"
api: "GET /api/v1/bot"
description: "Return public configuration for the bot tied to your API key"
---

## Overview

Returns configuration details about the bot. Useful for dynamically rendering the bot name, colors, and feature flags in your custom UI.

**Required scope:** `read`

## Response

<ResponseField name="id" type="string">
  Unique bot identifier (UUID).
</ResponseField>

<ResponseField name="name" type="string">
  Display name of the bot.
</ResponseField>

<ResponseField name="welcome_message" type="string">
  The first message the bot sends when a conversation starts.
</ResponseField>

<ResponseField name="primary_color" type="string">
  Hex color used for the bot's widget UI (e.g. `"#f97316"`).
</ResponseField>

<ResponseField name="selected_model" type="string">
  The AI model the bot uses. One of `"gemini"`, `"openai"`, `"anthropic"`, `"openrouter"`.
</ResponseField>

<ResponseField name="lead_capture_enabled" type="boolean">
  Whether the bot is configured to capture visitor contact details.
</ResponseField>

<ResponseField name="lead_fields" type="array">
  List of lead fields the bot collects (e.g. `["name", "email", "phone"]`).
</ResponseField>

<ResponseField name="calendar_scheduling_enabled" type="boolean">
  Whether the bot can book meetings via Google Calendar or Calendly.
</ResponseField>

<ResponseField name="meeting_provider" type="string">
  The calendar provider: `"google"`, `"calendly"`, or `null`.
</ResponseField>

<ResponseField name="response_language" type="string">
  Forced reply language code (e.g. `"fr"` for French), or empty string for automatic language mirroring.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>
