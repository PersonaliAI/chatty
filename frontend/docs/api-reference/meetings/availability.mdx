# Get Meeting Availability

Calculates open booking slots by evaluating working hours, existing calendar events (Google Calendar / Microsoft Outlook), buffer times, and maximum daily caps.

## Query Parameters

<ParamField query="bot_id" type="string" required>
  The unique ID of the bot.
</ParamField>

<ParamField query="date" type="string" required>
  Target date in `YYYY-MM-DD` format.
</ParamField>

<ParamField query="timezone" type="string">
  Visitor's IANA timezone (e.g. `America/New_York`, `Europe/London`, `Asia/Colombo`). If omitted, returns slots in the bot's configured primary timezone.
</ParamField>

---
