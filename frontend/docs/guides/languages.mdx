## Default behaviour

By default, the bot **mirrors the visitor's language** — if a visitor writes in French, the bot replies in French, even if your knowledge base is in English. The underlying AI handles translation automatically.

## Forcing a single language

To make the bot always reply in one language regardless of what the visitor writes — go to **Agent Settings → Response Language** and pick a language.

This is useful when:
- You need consistent transcripts for your CRM or analytics
- Your support team only reads one language
- Local regulations require a specific language

## Set language via API

You can read the bot's current language setting via `GET /api/v1/bot`:

```json
{
  "response_language": "fr"
}
```

An empty string (`""`) means the bot mirrors the visitor's language (default).

To change the language, use the dashboard. Language configuration is a bot-level setting, not an API key setting.

## Knowledge base language

Your knowledge base content can be in **any language**. The AI retrieves the relevant content and responds in the forced language (or the visitor's language), translating as needed.

For best accuracy, keep your knowledge base in the same language as your primary audience.
