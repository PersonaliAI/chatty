## What is Chatty?

**Chatty** is an AI chatbot platform that lets you build, train, and deploy intelligent chat assistants for your website, mobile app, or any product — without writing a single line of AI code.

The **Chatty API** gives you programmatic access to your bots: send messages, read leads, manage your knowledge base, and pull analytics — all from your own backend or automation workflow.

## Base URL

All API requests are made to:

```
https://chatty-api-376030619262.us-central1.run.app
```

## Quick example

```bash
curl -X POST https://chatty-api-376030619262.us-central1.run.app/api/v1/chat \
  -H "Authorization: Bearer chatty_sk_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"text": "What are your pricing plans?", "session_id": "user-abc"}'
```

```json
{
  "reply": "We offer three plans: Starter (free), Pro ($29/mo), and Business ($99/mo). The Pro plan includes unlimited bots and 10,000 messages per month. Would you like more details on any specific plan?",
  "session_id": "user-abc"
}
```
