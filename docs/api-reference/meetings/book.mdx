# Book Meeting

Creates a calendar appointment on the host's connected Google Calendar or Microsoft Outlook account, sends calendar invitations, and saves the meeting record in Chatty.

## Request Body

<ParamField body="bot_id" type="string" required>
  The unique ID of the bot.
</ParamField>

<ParamField body="session_id" type="string">
  The active visitor chat session ID to associate the meeting with.
</ParamField>

<ParamField body="start_time" type="string" required>
  ISO-8601 formatted start time (e.g. `2026-09-15T09:00:00-04:00`).
</ParamField>

<ParamField body="end_time" type="string" required>
  ISO-8601 formatted end time (e.g. `2026-09-15T09:30:00-04:00`).
</ParamField>

<ParamField body="name" type="string" required>
  Full name of the attendee.
</ParamField>

<ParamField body="email" type="string" required>
  Email address of the attendee.
</ParamField>

<ParamField body="phone" type="string">
  Phone number of the attendee.
</ParamField>

<ParamField body="notes" type="string">
  Optional agenda or discussion topics provided by the visitor.
</ParamField>
