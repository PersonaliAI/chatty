# Auto-Assign Queue Dispatch

Scans the unassigned ticket queue for the bot and automatically routes tickets to online agents who have available capacity.

## Query Parameters

<ParamField query="bot_id" type="string" required>
  The unique ID of the bot.
</ParamField>

---

## Behavior
1. Selects up to 20 unassigned tickets ordered by `last_message_at`.
2. Queries agents currently marked `online` in `chatty_agent_presence`.
3. Dispatches tickets in a round-robin cycle to the agent with the lowest active workload under their `max_capacity`.
4. Updates each dispatched ticket with the agent's identity and sets `ai_paused = True`.
