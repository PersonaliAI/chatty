## Overview

The Chatty embed widget is a standalone assistant that you add to any webpage with a single `<script>` tag. It renders as native vector HTML/SVG elements inside an isolated Shadow DOM container, guaranteeing 100% razor-sharp typography and icons at any zoom level with zero CSS conflicts.

It works on HTML, WordPress, Shopify, Webflow, Wix, Squarespace, and any other platform that lets you add custom HTML.

No API key is required - the widget authenticates automatically by bot ID.

## Installation

### 1. Get your bot ID

In the Dashboard, go to **Embed & Integrate → Embed Code**. Copy your bot ID - it looks like `a1b2c3d4-e5f6-7890-abcd-ef1234567890`.

### 2. Add the script tag

Paste this before the closing `</body>` tag of your page:

```html
<script
  src="https://chatty.personaliai.com/widget.js"
  data-id="YOUR_BOT_ID"
  defer
></script>
```

That's it. A chat bubble will appear in the bottom-right corner.

## Platform guides

<AccordionGroup>

  <Accordion title="WordPress">
    Install the official **[PersonaliAI Customer Support Chatbot](https://wordpress.org/plugins/personaliai-customer-support-chatbot)** plugin directly from **Plugins → Add New Plugin** in your WordPress admin (or from the [WordPress.org Plugin Directory](https://wordpress.org/plugins/personaliai-customer-support-chatbot)).

    Once activated, navigate to **Settings → PersonaliAI Chatbot** and enter your **Bot ID**. Your AI chatbot will immediately appear across your site with zero code editing required.

    *Note: WordPress.org directory search indexing can take up to 72 hours following approval. If directory search is still updating in your region, download the plugin ZIP directly from WordPress.org and upload via Plugins → Add New → Upload Plugin.*

    **Alternative (Manual Code Snippet)**:
    If you prefer not using a plugin, paste the script tag into your theme's `footer.php` before `</body>`, or add this snippet to your theme's `functions.php`:

    ```php
    function chatty_widget() { ?>
      <script src="https://chatty.personaliai.com/widget.js" data-id="YOUR_BOT_ID" defer></script>
    <?php }
    add_action('wp_footer', 'chatty_widget');
    ```
  </Accordion>

  <Accordion title="Shopify">
    In your Shopify admin, go to **Online Store → Themes → Edit Code**. Open `theme.liquid` and paste the script just before `</body>`.
  </Accordion>

  <Accordion title="Webflow">
    In **Project Settings → Custom Code**, paste the script into the **Footer Code** section. Publish your site to apply.
  </Accordion>

  <Accordion title="Wix">
    In the Wix Editor, click **Settings → Custom Code**, then add the script to the **Body - end** section. Set it to load on **All Pages**.
  </Accordion>

  <Accordion title="Squarespace">
    Go to **Settings → Advanced → Code Injection** and paste the script into the **Footer** section.
  </Accordion>

  <Accordion title="Next.js / React">
    Add the script tag to your root layout using Next.js's built-in Script component:

    ```tsx
    import Script from "next/script";

    export default function Layout({ children }) {
      return (
        <>
          {children}
          <Script
            src="https://chatty.personaliai.com/widget.js"
            data-id="YOUR_BOT_ID"
            strategy="afterInteractive"
          />
        </>
      );
    }
    ```

    For plain React (Vite / CRA), add the standard script tag to your `index.html` before `</body>`.

    Renders as native vector DOM elements inside an isolated Shadow Root - zero iframes, 100% sharp at any zoom level.
  </Accordion>

  <Accordion title="Inline Full-Page Embed">
    If you want a dedicated in-page chat window instead of a floating bubble:

    ```html
    <iframe
      src="https://chatty.personaliai.com/embed/YOUR_BOT_ID"
      width="100%"
      height="650"
      style="border: none; border-radius: 16px;"
      allow="clipboard-write; microphone; notifications"
    ></iframe>
    ```

## Customisation

All visual settings (colors, avatar, welcome message, widget style) are configured in **Dashboard → Customizer** - no code changes needed.
